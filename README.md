## 📌 Overview

**Payment System** — это микросервисная банковская система, в которой сейчас реализован первый сервис. Он отвечает за обработку входящих транзакций, работу со счетами и взаимодействие с Kafka и внешними REST-сервисами. Несмотря на то, что проект ещё не завершён полностью, уже реализованная часть демонстрирует владение современными технологиями: Spring Boot, Kafka, Docker, PostgreSQL, REST, а также проектирование микросервисов.

По мере развития проект будет расширяться до полноценной распределённой системы из нескольких сервисов.

---

## Текущие возможности

На данный момент реализован первый модуль — сервис аутентификации и управления пользователями. 
Его задача — регистрация пользователей, вход в систему и выдача JWT-токенов для дальнейшего обращения к другим сервисам. 
В будущем эта система будет расширяться новыми модулями

## Как запустить проект

### 1. Запуск через Docker

```
docker-compose up --build
docker compose -f docker-compose.yml -f docker-compose.test.yml --compatibility up --build
docker-compose -f docker-compose.yml --compatibility up --scale auth-service=3 --scale payment-service=3 --build

```

Сервисы автоматически поднимаются вместе с PostgreSQL и так же создаются все необходимые бд и таблицы в них.

## Что будет в финальной версии проекта

Когда проект будет завершён, он превратится в полноценную платёжную платформу с сервисом управления картами, балансами, переводами, статусами клиентов и проверкой лимитов. 
Каждый модуль будет выделен в отдельный контейнер, а авторизация через текущий Auth Service станет точкой входа для всех пользователей системы. 
В README со временем появится документация по API, примеры запросов, описание архитектуры и схема взаимодействия между сервисами.
